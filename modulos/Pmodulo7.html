Módulo 7. Printf y scanf

Modulo 7

Printf & scanf

Programación

¿Qué es printf y scanf?

Son las entradas y salidas de información que sirven para que podamos interactuar con un programa. Por ejemplo, podemos escribir un dato como nuestra edad o nuestro nombre, y el programa puede recibirlo y después mostrarnos un resultado. En C usamos principalmente scanf() para recibir información y printf() para mostrarla en la pantalla.

¿Cómo los utilizamos?

01

printf() es una función que usamos en C para mostrar información en la pantalla. Con ella podemos mostrar mensajes, números, resultados de operaciones y también información que esté guardada en una variable. Es muy útil porque nos permite comunicarnos con la persona que está usando el programa.

printf("Hola, bienvenido");

printf() sirve para mostrar en la pantalla lo que queremos que el usuario pueda ver.

02

scanf() es una función que usamos en C para recibir información que escribe el usuario. Por ejemplo, podemos pedirle su edad, una nota o cualquier otro dato, y guardar esa información en una variable para utilizarla después en el programa.

int edad;

scanf("%d", &edad);

scanf() sirve para recibir datos del usuario y guardarlos en una variable para poder utilizarlos después.

¿Cómo funcionan juntos?

printf() y scanf() pueden trabajar juntos para que el programa sea más interactivo. Primero usamos printf() para mostrar un mensaje o pedirle un dato al usuario, y después usamos scanf() para recibir esa información y guardarla en una variable. Luego podemos utilizar ese dato para realizar operaciones o mostrar un resultado.

int edad;

printf("Escribe tu edad: ");
scanf("%d", &edad);

printf("Tu edad es %d", edad);

Ejemplos

Podemos usar printf() y scanf() en diferentes situaciones para que el programa pueda mostrar mensajes y recibir información del usuario. Estos son algunos ejemplos sencillos:

Mostrar un mensaje

printf("Hola, bienvenido");

Pedir y guardar datos

int edad;
printf("Escribe tu edad: ");
scanf("%d", &edad);

Hacer operaciones

int a, b;
scanf("%d %d", &a, &b);
printf("Resultado: %d", a + b);

Errores comunes

Cuando estamos empezando a usar printf() y scanf(), es normal cometer algunos errores al escribir el código. Muchas veces son pequeños detalles, como olvidar un símbolo, escribir mal una función o utilizar un tipo de dato incorrecto. Estos errores pueden hacer que el programa no funcione correctamente o que aparezca un mensaje de error.

Olvidar el ;

printf("Hola")

Escribir mal el printf

prinf("Hola");

Usar un formato incorrecto

float nota;
scanf("%d", &nota);

Olvidar el & en scanf()

int edad;
scanf("%d", edad);

Resumen

printf() y scanf() nos ayudan a que el programa pueda comunicarse con el usuario. Con printf() podemos mostrar mensajes, números o resultados en la pantalla, mientras que con scanf() podemos recibir datos que escribe el usuario y guardarlos para utilizarlos después. Al usar las dos funciones juntas, podemos hacer programas más interactivos y fáciles de usar.
