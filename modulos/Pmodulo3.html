Modulo 3

Diagramas de flujo y árboles de decisión

Programación

¿Qué son?

Un diagrama de flujo y un árbol de decisión son herramientas que se utilizan en programación para organizar y entender la lógica de un programa antes de escribir el código. El diagrama de flujo muestra paso a paso lo que debe hacer el programa, utilizando símbolos, procesos, decisiones y flechas para indicar el orden. Por otro lado, el árbol de decisión se enfoca en las diferentes opciones que puede tomar el programa dependiendo de una condición, mostrando caminos distintos según la respuesta. En pocas palabras, ambos ayudan a visualizar cómo funciona un programa y qué decisiones debe tomar en cada situación.

Diagrama de flujo

Un diagrama de flujo es una representación gráfica que nos ayuda a organizar los pasos que debe seguir un programa. Utiliza figuras, símbolos y flechas para mostrar qué sucede primero, qué decisiones se toman y cuál es el resultado final. Es muy útil para entender la lógica de un programa antes de empezar a escribir el código.

Elementos

Indica el inicio o el final del programa.

Representa una acción o proceso.

Representa una condición o decisión.

Muestran el orden en que se ejecutan los pasos.

Árbol de decisión

Un árbol de decisión es una herramienta que podemos usar en programación para organizar las diferentes opciones que puede tomar un programa. Comienza con una condición o pregunta y, dependiendo de si se cumple o no, el programa sigue un camino diferente hasta llegar a un resultado.

  • Inicio / Fin: indica dónde comienza y termina el programa.
  • Proceso: representa una acción o instrucción que realiza el programa.
  • Decisión: muestra una condición que puede tener diferentes respuestas, como Sí / No.
  • Flechas: indican el orden y la dirección que sigue el programa.
  • Entrada / Salida: representa cuando el programa recibe o muestra información.

A diferencia del diagrama de flujo, el árbol de decisión tiene elementos un poco diferentes. Se basa principalmente en preguntas o condiciones, ramas que muestran las opciones y resultados que indican qué pasa según la decisión que tomemos.

Ejemplos de diagrama de flujo

Saber si una persona es mayor de edad

  1. INICIO
  2. Pedir edad
  3. ¿Edad >= 18?
  4. SÍ "Mayor"NO "Menor"
  5. FIN

Sumar dos números

  1. INICIO
  2. Pedir número 1
  3. Pedir número 2
  4. Sumar
  5. Mostrar resultado
  6. FIN

Saber si una nota es aprobatoria

  1. INICIO
  2. Pedir nota
  3. ¿Nota >= 3.0?
  4. SÍ "Aprobó"NO "No aprobó"
  5. FIN

Resumen

El diagrama de flujo y el árbol de decisión son herramientas que nos ayudan a organizar la lógica de un programa antes de escribir el código. El diagrama de flujo muestra los pasos que debe seguir el programa, utilizando símbolos y flechas para representar procesos, decisiones y resultados. Por otro lado, el árbol de decisión se enfoca en las diferentes opciones que puede tomar el programa dependiendo de una condición, mostrando sus posibles caminos y resultados. En pocas palabras: el diagrama de flujo muestra el proceso paso a paso y el árbol de decisión muestra las diferentes decisiones que puede tomar el programa.
