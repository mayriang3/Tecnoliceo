Modulo 7

Entradas y salidas en Arduino: señales digitales y analógicas

Electrónica

¿Cómo se comunica Arduino con el mundo?

Arduino se comunica con el exterior mediante sus pines. Un pin puede recibir información (entrada), como el estado de un pulsador o la lectura de un sensor, o puede enviar información (salida), como encender un LED o mover un motor. Además, esas señales pueden ser digitales o analógicas.

Los cuatro casos posibles

  • Entrada digital: lee si algo está activado o desactivado (pulsador, interruptor).
  • Salida digital: enciende o apaga un componente (LED, buzzer, relé).
  • Entrada analógica: lee un valor que varía de forma continua (potenciómetro, sensor de luz).
  • Salida analógica (PWM): controla cuánta energía recibe un componente (brillo de un LED, velocidad de un motor).

Objetivos del módulo

1

Diferenciar señales digitales y analógicas.

2

Configurar pines como entrada o salida con pinMode().

3

Leer y escribir valores con digitalRead, digitalWrite, analogRead y analogWrite.

4

Programar circuitos sencillos que combinen entradas y salidas.

Señal digital y señal analógica

Señal digital

Solo tiene dos estados posibles: HIGH (5 V, encendido) o LOW (0 V, apagado).

Ejemplo: un pulsador presionado o sin presionar.

Señal analógica

Puede tomar cualquier valor dentro de un rango continuo, por ejemplo entre 0 V y 5 V.

Ejemplo: la posición de un potenciómetro.

Comparación de las cuatro funciones

Función Tipo Valores Pines (Arduino UNO)
digitalRead(pin) Entrada digital HIGH o LOW 2 a 13 (y A0 a A5 como digitales)
digitalWrite(pin, valor) Salida digital HIGH o LOW 2 a 13 (y A0 a A5 como digitales)
analogRead(pin) Entrada analógica 0 a 1023 A0 a A5
analogWrite(pin, valor) Salida analógica (PWM) 0 a 255 3, 5, 6, 9, 10 y 11 (marcados con ~)

Salidas digitales

Se usan para encender o apagar componentes. Primero se configura el pin como salida y luego se le envía HIGH o LOW.

pinMode(pin, OUTPUT); // configura el pin como salida digitalWrite(pin, HIGH); // envía 5 V (encendido) digitalWrite(pin, LOW); // envía 0 V (apagado)

Importante: un LED siempre debe llevar una resistencia en serie (por ejemplo, 220 Ω) para limitar la corriente. Puedes calcularla con la Ley de Ohm del Módulo 2.

Entradas digitales

Permiten saber si un pulsador o interruptor está activado. El pin se configura como entrada y se lee con digitalRead().

pinMode(pin, INPUT); // entrada (requiere resistencia externa) pinMode(pin, INPUT_PULLUP); // entrada con resistencia interna a 5 V int estado = digitalRead(pin); // devuelve HIGH o LOW

¿Por qué usar INPUT_PULLUP?

  • Un pin de entrada sin conexión definida "flota" y lee valores al azar.
  • Con INPUT_PULLUP, el pin lee HIGH por defecto gracias a una resistencia interna.
  • El pulsador se conecta entre el pin y GND: al presionarlo, el pin lee LOW.
  • Así no necesitas agregar una resistencia externa al circuito.

Entradas analógicas

Arduino UNO convierte el voltaje de los pines A0 a A5 en un número entero entre 0 y 1023 (conversor de 10 bits). Con 0 V lee 0 y con 5 V lee 1023.

int valor = analogRead(A0); // valor entre 0 y 1023 float voltaje = valor * 5.0 / 1023.0; // convierte a voltios

Potenciómetro

Resistencia variable que entrega un voltaje distinto según la posición de su perilla.

Sensor de luz (LDR)

Su resistencia cambia con la cantidad de luz que recibe.

Sensor de temperatura

Entrega un voltaje que depende de la temperatura del ambiente.

Salidas analógicas: PWM

Arduino UNO no tiene un verdadero convertidor digital a analógico. Simula una salida analógica con PWM (modulación por ancho de pulso): enciende y apaga el pin muy rápido, y el porcentaje de tiempo encendido define la energía que recibe el componente.

analogWrite(pin, 0); // siempre apagado (0 %) analogWrite(pin, 127); // mitad del tiempo encendido (50 %) analogWrite(pin, 255); // siempre encendido (100 %)

Recuerda: analogWrite solo funciona en los pines con el símbolo ~ (3, 5, 6, 9, 10 y 11 en Arduino UNO).

Ejemplo práctico 1: LED intermitente (salida digital)

Un LED conectado al pin 13 que se enciende y se apaga cada segundo.

Código

void setup() { pinMode(13, OUTPUT); } void loop() { digitalWrite(13, HIGH); delay(1000); digitalWrite(13, LOW); delay(1000); }

Cómo funciona

  • setup(): se ejecuta una sola vez y configura el pin 13 como salida.
  • loop(): se repite sin parar.
  • delay(1000): espera 1000 milisegundos (1 segundo).

Ejemplo práctico 2: pulsador que enciende un LED (entrada y salida digital)

Pulsador en el pin 2 (con INPUT_PULLUP) y LED en el pin 13.

void setup() { pinMode(2, INPUT_PULLUP); pinMode(13, OUTPUT); } void loop() { if (digitalRead(2) == LOW) { // pulsador presionado digitalWrite(13, HIGH); } else { digitalWrite(13, LOW); } }
1

Leer la entrada

digitalRead(2) devuelve LOW si el pulsador está presionado.

2

Tomar la decisión

El if compara el estado leído con LOW.

3

Actuar en la salida

Se enciende o se apaga el LED del pin 13.

Ejemplo práctico 3: controlar el brillo con un potenciómetro

Potenciómetro en A0 (entrada analógica) y LED en el pin 9 (salida PWM).

void setup() { pinMode(9, OUTPUT); } void loop() { int lectura = analogRead(A0); // 0 a 1023 int brillo = map(lectura, 0, 1023, 0, 255); // convierte a 0 a 255 analogWrite(9, brillo); }

Clave: analogRead entrega valores de 0 a 1023 y analogWrite solo acepta de 0 a 255. La función map() convierte un rango en el otro.

Ejemplo de conversión

  • Lectura 0: brillo 0 (LED apagado).
  • Lectura 512: brillo 127 (aproximadamente medio brillo).
  • Lectura 1023: brillo 255 (brillo máximo).

Errores comunes con entradas y salidas

Evítalos para que tus circuitos funcionen a la primera.

01. Olvidar pinMode()

Sin configurar el pin, el LED puede no encender o la lectura ser incorrecta.

02. Conectar un LED sin resistencia

Un exceso de corriente puede dañar el LED o el pin de Arduino.

03. Dejar un pulsador sin INPUT_PULLUP

El pin queda flotando y lee valores aleatorios.

04. Usar analogWrite en un pin sin ~

Solo funciona con PWM en los pines 3, 5, 6, 9, 10 y 11 de Arduino UNO.

05. Confundir los rangos 0-1023 y 0-255

Usa map() para convertir la lectura analógica antes de escribirla.

Probar cada parte del circuito por separado te ayuda a encontrar fallos más rápido.

Resumen

Lo esencial que necesitas dominar: los pines de Arduino pueden ser entradas o salidas; las señales digitales solo tienen dos estados (HIGH y LOW); la lectura analógica va de 0 a 1023 y la escritura PWM va de 0 a 255; y pinMode, digitalRead, digitalWrite, analogRead y analogWrite son las cinco funciones base.
Con ellas puedes leer sensores, controlar LEDs y motores, y construir tus primeros proyectos con Arduino.
