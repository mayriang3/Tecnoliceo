Bucles o ciclos

Programación

¿Qué son los bucles o ciclos?

Los ciclos o bucles son estructuras que permiten que un programa repita una o varias acciones varias veces, sin tener que escribir el mismo código una y otra vez. En Python, los más utilizados son for y while, y cada uno funciona de una manera diferente según lo que necesitemos. Gracias a los ciclos, podemos hacer que nuestros programas sean más rápidos, prácticos y dinámicos, especialmente cuando necesitamos repetir una tarea muchas veces.

¿Cómo diferenciamos los ciclos?

01

El ciclo for se usa para repetir una acción una cantidad determinada de veces o recorrer elementos de una lista. Es útil cuando ya sabemos cuántas repeticiones necesitamos.

for i in range(5):
    print("Hola")

¿Qué hace? Imprime “Hola” 5 veces, porque range(5) indica que el ciclo debe repetirse cinco veces.

02

El ciclo while se usa para repetir una acción mientras se cumpla una condición. Continúa hasta que la condición deje de cumplirse.

numero = 1

while numero <= 5:
    print(numero)
    numero += 1

¿Qué hace? Muestra los números del 1 al 5, aumentando numero en 1 hasta que la condición ya no se cumpla.

¿Cómo funciona el FOR?

01

Primero, el programa establece qué acción quiere repetir y cómo funcionará el ciclo. Dependiendo del tipo de ciclo, podemos indicar una cantidad de repeticiones o una condición que debe cumplirse.

for i in range(3):

En este caso, indicamos que el ciclo se repetirá 3 veces.

02

Una vez iniciado el ciclo, el programa ejecuta la instrucción indicada cada vez que corresponde. Esta acción se repite automáticamente sin tener que escribirla varias veces.

print("Hola")

La instrucción hace que “Hola” aparezca en cada repetición.

03

Finalmente, cuando se cumple el número de repeticiones indicado o deja de cumplirse la condición, el ciclo se detiene. Después de esto, el programa continúa con las siguientes instrucciones.

Hola
Hola
Hola

Como el ciclo se repitió 3 veces, “Hola” aparece tres veces y luego termina.

¿Cómo funciona el WHILE?

01

Primero, el programa establece una condición que debe cumplirse para que el ciclo pueda comenzar y continuar funcionando.

numero = 1

while numero <= 3:

Aquí indicamos que el ciclo continuará mientras número sea menor o igual a 3.

02

Mientras la condición sea verdadera, Python ejecuta las instrucciones que están dentro del ciclo. En cada vuelta, el valor puede cambiar para que el ciclo avance.

print(numero)
numero += 1

El programa muestra el número y luego aumenta su valor en 1.

03

Cuando la condición deja de cumplirse, el while se detiene automáticamente y el programa continúa con las siguientes instrucciones.

1
2
3

Después de mostrar el 3, número pasa a ser 4 y la condición ya no se cumple.

Sintaxis de ciclos

01

Ciclo for
El for indica que empieza el ciclo. numero es la variable que va tomando diferentes valores. in indica que la variable recorrerá un rango y range(1, 6) establece los números desde 1 hasta 5. Los : indican que las instrucciones de abajo pertenecen al ciclo.

for numero in range(1, 6):
    print(numero)
02

Ciclo while
Primero se establece numero = 1 como valor inicial. while indica que el ciclo continuará mientras se cumpla la condición numero <= 5. Después, print(numero) muestra el número y numero += 1 aumenta su valor en cada repetición para que el ciclo pueda terminar.

numero = 1
while numero <= 5:
    print(numero)
    numero += 1

Errores comunes

En un ciclo while, la variable debe cambiar en algún momento. Si no lo actualizamos, el ciclo puede repetirse infinitamente.

Incorrecto
i = 5
while i < 5:
    print(i)
Correcto
i = 0
while i < 5:
    print(i)
    i += 1

Una condición mal escrita puede hacer que el ciclo no se ejecute o que se repita más veces de lo esperado.

Incorrecto
i = 5
while i < 5:
    print(i)
Correcto
i = 5
while i <= 5:
    print(i)
    i += 1

En Python, el último número de range() no se incluye, por lo que debemos tenerlo en cuenta al establecer el límite.

Incorrecto
for i in range(1, 5):
    print(i)
Correcto
for i in range(1, 6):
    print(i)

Si la condición de un while siempre es verdadera y la variable no cambia, el ciclo continuará indefinidamente.

Incorrecto
x = 1
while x > 0:
    print(x)
Correcto
for i in range(1, 6):
    print(i)

Resumen

Los ciclos o bucles son una herramienta de programación que sirve para repetir una o varias instrucciones varias veces sin tener que escribirlas de nuevo. Son muy útiles para hacer que un programa realice tareas de forma más rápida y organizada. En Python existen principalmente dos tipos: el ciclo for, que se utiliza cuando sabemos cuántas veces queremos repetir una acción, y el ciclo while, que repite las instrucciones mientras se cumpla una condición. En conclusión, los ciclos ayudan a ahorrar código y permiten que los programas sean más eficientes y fáciles de manejar.
