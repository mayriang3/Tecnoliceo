Modulo 6

Introducción a Arduino y Arduino IDE

Electrónica

¿Qué es Arduino?

Arduino es una plataforma de desarrollo electrónico de código abierto que combina hardware y software. Integra una placa programable con el entorno Arduino IDE para crear proyectos interactivos. Es ideal para educación, robótica y automatización, y es fácil de usar tanto para principiantes como para profesionales.

¿Qué es Arduino IDE?

Arduino IDE (Entorno de Desarrollo Integrado) es un software gratuito y de código abierto diseñado específicamente para programar placas Arduino. Permite escribir, editar y organizar el código de manera sencilla, con una interfaz intuitiva accesible tanto para principiantes como para usuarios avanzados.

Funciones principales

El Arduino IDE ofrece cuatro funciones esenciales:

Escribir

Escribir código en lenguaje C/C++ simplificado.

Compilar

Compilar programas para verificar errores de sintaxis.

Cargar

Cargar el código directamente a la placa Arduino mediante USB.

Depurar

Depurar errores a través del monitor serial integrado.

Control y aplicaciones

Con Arduino IDE puedes controlar una gran variedad de dispositivos electrónicos: encender y apagar luces LED, manejar motores y servos, leer datos de sensores de temperatura, luz, humedad y distancia, y automatizar procesos completos en proyectos de robótica y electrónica.

Componentes de la placa Arduino

Hardware

  • Microcontrolador: el cerebro de la placa.
  • Pines digitales: ON/OFF.
  • Pines analógicos: valores de 0 a 1023.
  • Puerto USB: para programar y alimentar la placa.

Controles

  • Botón Reset: reinicia el programa.
  • Regulador de voltaje: protege el circuito de sobrecargas eléctricas.

LED pin 13

LED integrado en el pin 13 para pruebas rápidas. Ideal para verificar el funcionamiento del programa sin componentes externos.

Funciones principales de Arduino

  • Leer datos de sensores (temperatura, luz, humedad, distancia).
  • Controlar actuadores (LEDs, motores, relés).
  • Procesar información y tomar decisiones lógicas.
  • Comunicarse con otros dispositivos y módulos.
  • Automatizar procesos repetitivos de forma eficiente.
  • Crear prototipos rápidos de proyectos electrónicos.

Estructura básica de un programa Arduino

01 · setup()

void setup() { }

Se ejecuta una sola vez al iniciar el programa. Aquí se configuran los pines, se inician comunicaciones y se definen los parámetros iniciales del sistema antes de entrar al bucle principal.

02 · loop()

void loop() { }

Se ejecuta continuamente en bucle infinito. Contiene la lógica principal del programa: leer sensores, controlar actuadores, procesar datos y tomar decisiones de forma repetida.

Ejemplo práctico: parpadeo de LED

El programa Blink es el ejemplo más básico en Arduino. Configura el pin 13 como salida para controlar el LED integrado.

void setup() { pinMode(13, OUTPUT); // Pin 13 como salida } void loop() { digitalWrite(13, HIGH); // Enciende LED delay(1000); // Espera 1 segundo digitalWrite(13, LOW); // Apaga LED delay(1000); // Espera 1 segundo }

El programa enciende y apaga el LED repetidamente cada segundo, demostrando el ciclo continuo del loop().

Pasos para programar Arduino

1

Instalar Arduino IDE

Descárgalo desde arduino.cc.

2

Conectar la placa

Conecta la placa Arduino con un cable USB.

3

Escribir el código

Abre Arduino IDE y escribe el código.

4

Seleccionar la placa

Elige el modelo de placa en Herramientas → Placa.

5

Seleccionar el puerto

Elige el puerto COM correcto en Herramientas → Puerto.

6

Verificar el código

Presiona el botón ✓ para verificar el código.

7

Cargar el programa

Presiona el botón → para cargar el programa a la placa.

8

Observar el resultado

Observa el funcionamiento del programa.

Aplicaciones reales de Arduino

Domótica y robótica

Control de luces, temperatura y seguridad en el hogar. Robots móviles y brazos robóticos programados con Arduino para automatización.

Agricultura y transporte

Sistemas de riego automático inteligente y semáforos programables. Arduino optimiza procesos en campo y vías urbanas con sensores.

Salud, arte y educación

Monitores de signos vitales, instalaciones artísticas interactivas y proyectos STEM educativos.

Errores comunes y soluciones

Puerto incorrecto

Solución: verificar el Administrador de dispositivos.

Placa mal seleccionada

Solución: confirmar el modelo exacto de la placa.

Conexiones incorrectas

Solución: revisar el diagrama del circuito.

Olvidar cargar el código

Solución: presionar el botón de carga (→).

Errores de sintaxis

Solución: revisar los puntos y comas y las llaves.

Cable USB defectuoso

Solución: probar con otro cable.
