Programación en python

Programación

¿Qué es python y para qué se usa?

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general. Destaca por su sintaxis clara y legible, similar al inglés, lo que facilita su aprendizaje. Se emplea en inteligencia artificial, ciencia de datos, desarrollo web y automatización de tareas.

Cómo funciona

Python funciona mediante un proceso de interpretación en dos pasos. Primero, un programa toma tu archivo de texto y lo convierte en instrucciones compactas (bytecode); segundo, una máquina de software (la Máquina Virtual de Python) lee esas instrucciones y le ordena al procesador de tu computadora real que realice las acciones.

01

Traducción en tiempo real: No necesitas transformar tu programa en una aplicación instalable antes de usarlo; Python traduce y ejecuta el código al mismo tiempo mientras el programa está corriendo.

02

Gestión automática de memoria: Python incluye un "recolector de basura" interno que limpia y libera la memoria de la computadora automáticamente cuando dejas de usar un dato, evitando que tú tengas que hacerlo a mano.

03

Lectura secuencial: El sistema lee tu documento de arriba hacia abajo; si encuentra un error en la mitad del código, todo lo anterior se ejecutará correctamente y el programa se detendrá justo en la línea que tiene la falla.

Sintaxis básica

01

Variables sin símbolos raros: Para guardar un dato no necesitas usar palabras técnicas ni símbolos de dinero; simplemente escribes el nombre que tú quieras, el signo de igual y el valor. 

nombre = "Juan"
edad = 15

Aquí simplemente se escribe el nombre de la variable, el signo = y el dato que queremos guardar.

02

La indentación es obligatoria: En lugar de usar llaves {} para agrupar bloques de código (como en los bloques if o bucles), Python te obliga a usar cuatro espacios de separación (sangría) al inicio de la línea para saber qué instrucciones van dentro de otras. 

edad = 18
if edad >= 18:
    print("Eres mayor de edad")

En este ejemplo, los cuatro espacios antes de print() indican que esa instrucción pertenece al bloque del if. Sin la indentación, Python produciría un error.

03

Texto entre comillas y comentarios con '#': Todo el texto común y corriente que quieras mostrar en pantalla debe ir cerrado entre comillas (" "), y si quieres escribir comentarios para ti mismo que Python ignore, debes empezar la línea con el símbolo numeral (#).

# Este es un comentario
print("Hola, mundo")
print("Estoy aprendiendo Python")

Aquí, lo que empieza con # es un comentario y Python lo ignora. El texto dentro de " " se muestra en pantalla.

Ejemplos

Mostrar un mensaje

En Python, mostrar un mensaje consiste en utilizar la función print() para presentar información en la pantalla. Esta información puede ser un texto, un número o incluso el contenido de una variable. Es una de las instrucciones más sencillas y sirve para que el programa pueda comunicar resultados o mensajes al usuario.

print("Hola, mundo")
print("Bienvenido a Python")

Usar variables

Las variables son espacios donde el programa puede guardar información para utilizarla posteriormente. En Python, crear una variable es sencillo: se escribe un nombre, el signo = y el valor que queremos almacenar. Las variables pueden guardar diferentes tipos de datos, como textos, números o valores booleanos.

nombre = "Carlos"
edad = 15

print(nombre)
print(edad)

Tomar decisiones con if

Las condiciones permiten que el programa elija qué hacer según una situación. La instrucción if evalúa una condición: si es verdadera, ejecuta el bloque de código que está indentado debajo; si es falsa, lo ignora. Con else se puede indicar qué hacer cuando la condición no se cumple. Recuerda poner dos puntos (:) al final de la línea del if y del else.

edad = 18

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

Errores comunes

SyntaxError

Ocurre cuando el código no cumple las reglas de escritura de Python, por ejemplo, cuando falta un paréntesis o :.

Código incorrecto:
if edad >= 18
print("Mayor de edad")
Código correcto:
if edad >= 18:
    print("Mayor de edad")

NameError

Ocurre cuando se utiliza una variable o nombre que Python no reconoce porque no existe o está escrito incorrectamente.

Código incorrecto:
nombre = "Carlos"
print(nomre)
Código correcto:
nombre = "Carlos"
print(nombre)

TypeError

Ocurre cuando intentamos realizar una operación con datos de tipos incompatibles, como texto y números.

Código incorrecto:
edad = 15
print("Tengo " + edad + " años")
Código correcto:
edad = 15
print("Tengo " + str(edad) + " años")

Resumen

Python es un lenguaje de programación de alto nivel, claro y fácil de leer, que se usa en inteligencia artificial, ciencia de datos, desarrollo web y automatización. Su intérprete convierte el código en bytecode y lo ejecuta línea por línea, de arriba hacia abajo, mientras gestiona la memoria de forma automática.
En la sintaxis básica recuerda tres reglas: las variables se crean con el signo =, la indentación de cuatro espacios es obligatoria para agrupar bloques, y los comentarios empiezan con #. Con print() puedes mostrar mensajes, con variables guardas datos y con if tomas decisiones. Por último, aprende a reconocer los errores más comunes: SyntaxError (error de escritura), NameError (nombre no definido) y TypeError (tipos de datos incompatibles).
