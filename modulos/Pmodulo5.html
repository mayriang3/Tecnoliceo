Programación en C

Programación

¿Qué es la programación en C?

La programación en C es una forma de crear programas usando instrucciones que el computador puede entender. Con C podemos hacer que un programa calcule, muestre información, tome decisiones y repita acciones. Para escribir en C usamos cosas como variables, condiciones, ciclos y funciones. Es un lenguaje muy importante porque ayuda a entender las bases de la programación.

Se le dice C porque fue creado como una evolución de un lenguaje anterior llamado B. Así nació el nombre C, simple pero muy importante en la programación.

¿Cómo escribimos en C?

Para programar en C debemos seguir unas reglas llamadas sintaxis. Estas nos indican cómo escribir las instrucciones para que el computador pueda entenderlas y ejecutarlas. Algunas partes importantes son main(), printf(), las variables y el uso de ;.

  • int → Indica que trabajamos con un número entero.
  • main() → Es donde comienza el programa.
  • printf() → Sirve para mostrar algo en pantalla.
  • ; → Indica que una instrucción terminó.
#include <stdio.h>

int main() {
    printf("Hola");
    return 0;
}

Este pequeño programa utiliza algunas de las partes básicas de la sintaxis de C y muestra la palabra “Hola” en la pantalla. De esta forma podemos ver cómo se escriben y organizan las instrucciones dentro de un programa.

Elementos básicos de C

Operadores

Los operadores son símbolos que utilizamos para realizar operaciones o comparar valores dentro de un programa. Nos permiten hacer cálculos y tomar decisiones.

int suma = 5 + 3;
int resta = 5 - 3;
int mayor = 5 > 3;
  • + → suma.
  • - → resta.
  • * → multiplicación.
  • / → división.
  • > → mayor que.
  • < → menor que.

Tipos de datos

Los tipos de datos indican qué clase de información podemos guardar en una variable. Cada tipo se utiliza para almacenar datos diferentes, como números, decimales o caracteres.

int edad = 15;
float promedio = 4.5;
char inicial = 'G';
  • int → números enteros.
  • float → números decimales.
  • char → un carácter o letra.

Cómo repetimos una acción

A veces necesitamos que un programa haga la misma acción varias veces. Para esto utilizamos los ciclos o bucles, como for y while.

01

Ciclo for
El for indica que empieza el ciclo. numero es la variable que va tomando diferentes valores. in indica que la variable recorrerá un rango y range(1, 6) establece los números desde 1 hasta 5. Los : indican que las instrucciones de abajo pertenecen al ciclo.

for numero in range(1, 6):
    print(numero)
02

Ciclo while
Primero se establece numero = 1 como valor inicial. while indica que el ciclo continuará mientras se cumpla la condición numero <= 5. Después, print(numero) muestra el número y numero += 1 aumenta su valor en cada repetición para que el ciclo pueda terminar.

numero = 1
while numero <= 5:
    print(numero)
    numero += 1

¿Cómo toma decisiones?

[Texto introductorio sobre las decisiones]

01

if se utiliza para que el programa compruebe si una condición se cumple. Cuando la condición es verdadera, el programa realiza las instrucciones que están dentro del if. Es una de las formas más básicas de hacer que un programa tome decisiones.

if edad >= 18:
    print("Eres mayor de edad")
02

elif se utiliza cuando queremos comprobar una nueva condición después de que la condición anterior no se cumplió. Podemos utilizar varios elif para que el programa pueda elegir entre diferentes opciones.

if nota >= 4:
    print("Muy bien")
elif nota >= 3:
    print("Aprobaste")

Ejemplo

Ahora vamos a juntar varios elementos que hemos visto para crear un pequeño programa. En este ejemplo usamos una variable, una condición y mostramos un mensaje en pantalla.

#include <stdio.h>

int main() {
    int edad = 15;

    if (edad >= 18) {
        printf("Eres mayor de edad");
    } else {
        printf("Eres menor de edad");
    }

    return 0;
}

Errores comunes

Al comenzar a programar es normal cometer algunos errores. Los más comunes ocurren por olvidar símbolos, escribir mal una instrucción o no cerrar correctamente una parte del código.

int edad = 15   // Falta ;
printf("Hola"   // Falta cerrar )
  • Olvidar el ;
  • No cerrar () o { }
  • Escribir mal el nombre de una función.
  • Usar una variable que no ha sido creada.

Resumen

La programación en C nos permite crear programas mediante instrucciones que el computador puede entender y ejecutar. Para hacerlo, utilizamos diferentes elementos como variables, tipos de datos, operadores, condiciones y ciclos, siguiendo unas reglas llamadas sintaxis. Aunque al principio pueden aparecer algunos errores, con la práctica podemos aprender a escribir programas cada vez más completos y útiles.
