Módulo 8. Condicionales

Modulo 8

Condicionales

Programación

Introducción

En programación, los programas no siempre necesitan realizar las mismas acciones. Dependiendo de los datos que reciban, pueden necesitar tomar decisiones diferentes. Los condicionales permiten que un programa analice una situación y decida qué acción realizar dependiendo de si una condición se cumple o no.

¿Qué son los condicionales?

Las condicionales en Python son instrucciones que permiten que un programa tome decisiones dependiendo de una situación. Estas funcionan evaluando si una condición se cumple o no y, según el resultado, ejecutan una acción determinada. Para esto se utilizan principalmente if, elif y else. Gracias a las condicionales, los programas pueden responder de diferentes maneras según los datos que reciban, por ejemplo, para saber si una persona es mayor de edad, si una nota es suficiente para aprobar o si hace frío o calor.

¿Cómo decide nuestro programa?

Cuando hacemos un programa, no siempre queremos que realice la misma acción. Dependiendo de la situación o de los datos que reciba, puede necesitar tomar una decisión diferente.
Para que esto sea posible, utilizamos los condicionales, que permiten comprobar si una determinada condición se cumple o no.
Por ejemplo, podemos hacer que un programa revise la nota de un estudiante. Si las notas van de 1 a 10 y se necesita una nota de 6 o más para aprobar, el programa puede comprobar la nota y mostrar un resultado diferente dependiendo de ella.
En este ejemplo, Python analiza la condición nota >= 6. Como la nota es 8, la condición se cumple y el programa muestra “Aprobaste”. Si la nota fuera 5, la condición no se cumpliría y aparecería “No aprobaste” por eso se utiliza else. De esta manera, los condicionales hacen que los programas sean más útiles, porque permiten que reaccionen de diferentes formas según los datos que reciben. 

nota = 8

if nota >= 6:
    print("Aprobaste")
else:
    print("No aprobaste")

¿Cómo funciona?

Los condicionales permiten que un programa tome decisiones según su condición. Primero, Python analiza si una situación es verdadera o falsa y, dependiendo del resultado, decide qué acción realizar.

01

El programa analiza una condición para saber si se cumple o no. Por ejemplo: ¿la nota es mayor o igual a seis? 

if nota >= 6:

Python comprueba si la condición es verdadera.

02

Si la condición es verdadera, Python realiza la instrucción que se encuentra dentro del if. 

print("Aprobaste")

El programa muestra el mensaje “Aprobaste”.

03

Si la condición es falsa, el programa puede realizar otra acción utilizando else. 

else:
    print("No aprobaste")

El programa muestra “No aprobaste”.

Sintaxis

01

if significa “si”. Se utiliza para probar una condición. Si la condición es verdadera, Python ejecuta las instrucciones que están dentro del if. 

if condicion:
    acción

if nota >= 8:
    print("Excelente")
02

elif significa “si no, si”. Se utiliza después de un if cuando queremos comprobar una condición diferente. Esto permite tener varias posibilidades dentro del programa. 

elif otra_condicion:
    otra_accion

elif nota >= 6:
    print("Aprobaste")
03

else significa “si no”. Se utiliza cuando ninguna de las condiciones anteriores se cumple. En este caso, Python realiza la acción dentro del else. 

else:
    acción

else:
    print("No aprobaste")

Ejemplos

Saber si una persona es mayor de edad

El programa compara la edad de la persona con 18. Si tiene 18 años o más, muestra que es mayor de edad; de lo contrario, indica que es menor. 

edad = 18

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

Revisar una nota

El programa revisa si la nota obtenida es igual o superior a 3.0. Si cumple esta condición, el estudiante aprueba; si no, reprueba. 

nota = 4.2

if nota >= 3.0:
    print("Aprobaste")
else:
    print("No aprobaste")

Comprobar la temperatura

El programa comprueba si hace mucho calor, si el clima está agradable o si hace frío utilizando if, elif y else. 

temperatura = 30

if temperatura > 30:
    print("Hace mucho calor")
elif temperatura >= 20:
    print("El clima está agradable")
else:
    print("Hace frío")

Errores comunes

Después de if, elif o else siempre deben ir dos puntos. Si los olvidamos, Python no puede interpretar correctamente la condición.

Incorrecto 
if edad >= 18
    print("Eres mayor de edad")
Correcto 
if edad >= 18:
    print("Eres mayor de edad")

= se utiliza para asignar un valor, mientras que == se utiliza para comparar. Usarlos incorrectamente puede hacer que la condición no funcione.

Incorrecto 
if edad = 18:
    print("Tienes 18 años")
Correcto 
if edad == 18:
    print("Tienes 18 años")

El código que pertenece a una condición debe tener una sangría. Sin ella, Python no sabe qué instrucciones debe ejecutar cuando la condición se cumple.

Incorrecto 
if nota >= 3:
print("Aprobaste")
Correcto 
if nota >= 3:
    print("Aprobaste")

if inicia una condición, elif permite comprobar otra posibilidad y else se utiliza cuando ninguna de las condiciones anteriores se cumple.

Incorrecto 
if temperatura > 30:
    print("Hace mucho calor")

if temperatura >= 20:
    print("Está agradable")
else:
    print("Hace frío")
Correcto 
if temperatura > 30:
    print("Hace mucho calor")
elif temperatura >= 20:
    print("Está agradable")
else:
    print("Hace frío")

Resumen

Los condicionales en Python permiten que el programa tome decisiones según una situación o dato. Se utilizan if, elif y else para comprobar diferentes condiciones.
Por ejemplo, pueden servir para saber si una persona es mayor de edad, si una nota es suficiente para aprobar o qué tipo de clima hay según la temperatura.
Al escribirlos, hay que tener cuidado con errores como olvidar los :, confundir = con ==, no usar correctamente la indentación o escribir mal los operadores.
