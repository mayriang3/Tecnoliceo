Cuestionario de conocimientos

Responde las siguientes 8 preguntas sobre la sintaxis básica del lenguaje C. Lee cuidadosamente cada pregunta y selecciona una sola respuesta.

1. Observa el siguiente programa en C:

#include <stdio.h>

int main() {
    printf("Hola mundo");
    return 0;
}

¿Para qué sirve la línea #include <stdio.h>?

2. En el programa anterior, ¿qué representa la función main()?

3. ¿Por qué es obligatorio colocar un punto y coma (;) al final de instrucciones como printf("Hola mundo"); en C?

4. Dentro de un programa en C, ¿qué función cumplen las llaves { } que aparecen después de int main()?

5. Observa el siguiente fragmento de código:

int edad;
float promedio;
char inicial;

¿Qué están representando estas tres líneas?

6. Observa el siguiente código:

int numero;
scanf("%d", &numero);

¿Qué hace la función scanf en este fragmento?

7. Observa el siguiente código:

// Este programa calcula el área de un cuadrado
int lado = 4;
/* La siguiente línea
  calcula el área */
int area = lado * lado;

¿Qué función cumplen las líneas que comienzan con // y las que están entre /* y */?

8. Observa el siguiente código:

int edad = 20;

if (edad == 18) {
    printf("Tiene 18 anios");
}

Si en lugar de edad == 18 se escribe por error edad = 18, ¿qué problema de sintaxis se presenta?
