1. ¿Qué es un bucle o ciclo dentro de un programa?

2. Un programa debe mostrar los números del 1 al 5, y se sabe exactamente cuántas veces se debe repetir la instrucción. ¿Qué tipo de bucle es más adecuado utilizar?

3. Observa el siguiente código en Python:

for i in range(5):
    print(i)

¿Qué valores se mostrarán en pantalla?

4. Un programa debe seguir pidiéndole una contraseña al usuario hasta que la escriba correctamente, pero no se sabe de antemano cuántos intentos necesitará. ¿Qué tipo de bucle es más adecuado en este caso?

5. Observa el siguiente código:

contador = 0

while contador < 5:
    print("Repitiendo")

¿Qué problema tiene este código?

6. Observa el siguiente código:

for numero in range(10):
    if numero == 4:
        break
    print(numero)

¿Qué valores se mostrarán en pantalla?

7. Observa el siguiente código:

for numero in range(5):
    if numero == 2:
        continue
    print(numero)

¿Qué diferencia existe entre break y continue según este ejemplo?

8. Observa el siguiente código:

suma = 0

for numero in [2, 4, 6]:
    suma = suma + numero

print(suma)

¿Qué patrón representa la variable suma dentro de este bucle?
