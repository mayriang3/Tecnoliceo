Responde las siguientes 8 preguntas sobre las estructuras condicionales. Lee cuidadosamente cada situación y selecciona una sola respuesta.

1. ¿Cuál es la función principal de una estructura condicional dentro de un programa?

2. Observa el siguiente código en Python:

edad = 18
if edad >= 18:
    print("Puede votar")

¿Qué ocurre cuando se ejecuta el programa?

3. ¿Qué diferencia existe principalmente entre if y else?

4. Un programa debe mostrar "Aprobado" si la nota es mayor o igual a 3.0 y "Reprobado" en cualquier otro caso. ¿Cuál estructura representa correctamente esta situación?

5. ¿Para qué se utiliza principalmente elif en Python?

6. Observa el siguiente código:

temperatura = 25

if temperatura > 30:
    print("Hace mucho calor")
else:
    print("La temperatura es moderada")

¿Qué mensaje aparecerá?

7. ¿Cuál de los siguientes es un error común al utilizar estructuras condicionales en Python?

8. Un estudiante quiere crear un programa que clasifique una nota de la siguiente manera:

4.5 o más: "Excelente"
3.0 a 4.4: "Aprobado"
Menor de 3.0: "Reprobado"

¿Qué estructura sería la más adecuada?
